## 0. Главное ограничение доказательной базы (читать первым)

- **Прямых данных о готовности платить (WTP) в нише исправителей раскладки нет**: ни опросов, ни прочитанных отзывов магазинов приложений (домены недоступны). Единственные **наблюдаемые** сигналы WTP — **цены, по которым продукты существуют** (Caramba Pro, Lang Switcher, экспандеры, утилиты) [R]. Наличие цены ≠ доказанный спрос: число покупателей неизвестно.
- Поэтому в колонке «за что заплатят» каждая строка помечена силой доказательства: **сильное** (несколько независимых источников о платном спросе), **среднее** (существуют платные продукты для этой задачи), **слабое** (только логика/аналогия), **нет**.
- Сегменты пересекаются; один человек может быть «разработчиком» и «пользователем мессенджеров».
- Общий фон доверия: в опросе Cisco 2024 (2 600+ респондентов, 12 стран) 51 % «Privacy Actives» меняли компанию из-за практик обработки данных; 75 % не покупают у тех, кому не доверяют данные [R: https://newsroom.cisco.com/c/r/newsroom/en/us/a/y2024/m10/how-safe-is-our-data-consumers-want-to-know.html]. Это не про переключатели, а общий фон.

## 2. Сегменты подробно

### 2.1 Обычные пользователи (RU/EN, дом)
- **Проблемы.** «ghbdtn» вместо «привет»; ложные автосрабатывания у Punto (N-02 [R]); потеря буфера (N-04 [R]); перегруз настроек (N-09 [R]); ненадёжный Alt+Shift в Windows 11 (N-06 [R]).
- **Нужные функции.** Одна клавиша, понятная по умолчанию; «ничего не сломать»; отмена (Ctrl+Z).
- **Чем пользуются.** Punto, Caramba Classic, стандартный переключатель Windows [R].
- **Базовое.** Конвертация бесплатно, без рекламы и без бандлинга [A; бандлинг Punto — источник недовольства R].
- **За что заплатят.** Доказательств **нет**. Caramba Pro $4,99/год [R] — максимум ориентира, число покупателей неизвестно.
- **Раздражение от бесплатных.** Бандлинг (Яндекс Браузер в установщике Punto [R]), «шпионит» (история 2010 [R]), заброшенность (N-07 [R]).
- **Помогут.** MI-11 (выбор хоткея), MI-14 (демо в онбординге), MI-15 («почему не сработало»).

### 2.2 Многоязычные пользователи (UK/RU/EN, + DE/PL/CZ, иврит и др.)
- **Контекст.** 4,43 млн украинцев под временной защитой в ЕС (июль 2026) — каждый с UK/RU/EN и часто местной раскладкой [R, см. MARKET_OVERVIEW §2].
- **Проблемы.** Переключатели «RU/EN» не понимают UK (Punto, по старым отзывам, не переключал украинский автоматически [R: https://qna.habr.com/q/251343 через поиск]); слова, совпадающие в UK/RU (MySwitcher решает отдельным словарём [R]); 3+ раскладки → неясно, «в какую» конвертировать.
- **Нужные функции.** Выбор пары/направления; украинский пакет (і, ї, є, ґ); UI на украинском.
- **Чем пользуются.** Kright (любые пары, распознавание 11 языков [V]), RuSwitcher (любые установленные [V]), MySwitcher [R].
- **Базовое.** Поддержка своего языка — **базовая** функция: у OSS она бесплатна [V].
- **За что заплатят.** **Слабое** доказательство. Рекомендация: языки — Free (см. PREMIUM_FEATURE_RESEARCH P-04).
- **Раздражение.** Продукты Яндекса для части украинских пользователей неприемлемы [A, R: санкции 2017].

### 2.3 Студенты
- **Проблемы.** Набор конспектов на двух языках, формулы/латиница в кириллическом тексте; ограниченный бюджет.
- **Нужные функции.** Надёжная конвертация; транслитерация по запросу (шаблон макроса); работа в браузерных редакторах (Google Docs — D-19(a): только выделение до S-2).
- **Чем пользуются.** Бесплатные переключатели, стандартные средства [A].
- **За что заплатят.** **Нет** доказательств. Рынок инструментов обычно даёт студентам скидки/бесплатно [A]; проверяемого источника в этой сессии нет.
- **Вывод [A].** Не строить платные функции под студентов; Free должен быть полноценным.

### 2.4 Преподаватели
- **Проблемы.** Многоязычные материалы, одинаковые комментарии к работам, типографика («ёлочки», тире).
- **Нужные функции.** Шаблоны текста по хоткею, типограф, регистр (MI-06).
- **Чем пользуются.** Экспандеры (PhraseExpress бесплатно для личного [R]), автозамена Word [A].
- **За что заплатят.** **Слабое**: больше слотов/шаблонов — по аналогии с экспандерами.
- **Ограничение KeySwitch.** Нет триггеров-аббревиатур (нужен перехват набора — запрещено D-14); только хоткей/палитра.

### 2.5 Офисные сотрудники
- **Проблемы.** Outlook/Teams/1С/CRM; лишний Enter в чате (N-15, RuSwitcher исправлял Enter в Outlook [V]); запрет ИБ на установку «кейлоггеров» [R: Grammarly].
- **Нужные функции.** Безопасность для ИБ (MI-02), отказ в паролях, не трогать буфер истории (D-13).
- **За что заплатят.** Лично — нет; работодатель — **см. AGENT 17**.

### 2.6 Разработчики
- **Проблемы.** Терминалы не принимают запись через Accessibility (Kright: fallback на эмуляцию клавиш [V]); VS Code не отдаёт позицию курсора [V RuSwitcher]; vim-команды в русской раскладке (`langmap` — давняя тема Habr/LOR [R: https://habr.com/en/articles/98393 ; https://qna.habr.com/q/544896]); RDP [V SimpleSwitcher].
- **Нужные функции.** Исключения для терминалов/IDE (D-05: терминалы — по умолчанию в исключениях), хоткеи F13–F24 (MI-11), макросы-трансформации (camelCase↔snake_case, экранирование, JSON-форматирование) — **в песочнице**.
- **Чем пользуются.** AutoHotkey, PowerToys, Raycast, Espanso, SimpleSwitcher [V/R].
- **Базовое.** Open source, проверяемая сборка, отсутствие сети [A; сигнал — OSS-конкуренты выносят это в README V].
- **За что заплатят.** **Среднее**: разработчики платят за инструменты (Sublime Text $99 разово с 3 годами обновлений, Typora $14,99 на 3 устройства [R]; Raycast Pro ~$8–10/мес [R]). Ценность для них — **больше слотов, продвинутый API макросов, профили** [A].
- **Раздражение.** AV-ложные срабатывания AHK [V], «скрипты с полными правами» [A].

### 2.7 IT-специалисты
- **Проблемы.** RDP/виртуальные машины, массовая установка, совместимость с политиками, «кейлоггер-подобное» ПО.
- **Нужные функции.** Тихая установка, winget, документ для ИБ (MI-02), авто-пауза в RDP (MI-13).
- **За что заплатят.** Корпоративное — **AGENT 17**. Лично — слабое.

### 2.8 Пользователи мессенджеров
- **Проблемы.** Telegram Desktop, WhatsApp (WebView2 не отдаёт ничего через UIA — по тестам Kright [V]), Discord, веб-чаты (RuSwitcher исправлял «потерю слова в веб-чатах» [V]); случайная отправка (N-15).
- **Нужные функции.** Режим «выделение + Ctrl+C по профилю» (D-19(d)), никакого Enter, понятный отказ.
- **За что заплатят.** **Нет**. Это массовый базовый сценарий → Free.

### 2.9 «Тяжёлые» пользователи текста (авторы, переводчики, поддержка, копирайтеры)
- **Проблемы.** Повторяющиеся ответы, типографика, очистка форматирования при вставке (существуют отдельные утилиты PureText — бесплатно, в Microsoft Store [R: https://stevemiller.net/PureText/]; TextSoap — платно [R, цены устаревшие]).
- **Нужные функции.** Палитра сниппетов по хоткею, шаблоны с переменными (дата, выделение), цепочки трансформаций.
- **Чем пользуются.** PhraseExpress (100–250 € за проф. использование [R]), TextExpander (~$40/год [R]), aText ($29,99 навсегда [R]), Espanso [R].
- **За что заплатят.** **Среднее** (существование платной категории экспандеров). Это **самый вероятный платящий B2C-сегмент** [A].
- **Раздражение.** Облако обязательно (TextExpander [A]); подписки и повышения цен [R]; сложность YAML (Espanso [R]).

## 3. Что из этого следует для Free/Premium [A]

1. **Free = всё, что нужно сегментам 2.1–2.5 и 2.8**: конвертация, безопасность, языки, совместимость, понятные отказы, 1 слот макроса со всеми типами. Ограничивать это — значит проиграть бесплатным Punto/Kright.
2. **Платящие сегменты — 2.6 (разработчики) и 2.9 (тяжёлые пользователи текста)**, и платят они за **расширенную Macro Studio** (слоты, библиотека, палитра, профили), а не за переключение раскладки.
3. **Корпоративный покупатель** (2.5, 2.7) — отдельная линия AGENT 17.
4. **Обязательная проверка до `COMMERCIAL_PRODUCT_PROPOSAL`:** 10–20 интервью с пользователями сегментов 2.6 и 2.9 (задача Product Analyst, с согласия владельца), т. к. сила доказательств WTP сейчас максимум «средняя».
