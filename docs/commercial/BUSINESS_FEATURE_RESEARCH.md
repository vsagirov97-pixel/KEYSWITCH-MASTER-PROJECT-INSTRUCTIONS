## 0. Как читать
- **12 критериев V4:** (1) аудитория · (2) проблема · (3) спрос · (4) конкуренты · (5) готовность платить · (6) ценность для пользователя · (7) техническая сложность — *предварительно, подтверждает AGENT 03* · (8) стоимость поддержки · (9) производительность · (10) безопасность — *предварительно, для CISO* · (11) GDPR/право — *предварительно, для CLO* · (12) коммерческая ценность.
- Шкалы [A]: спрос/ценность/коммерция — Низк./Средн./Высок.; сложность — S/M/L/XL; поддержка — Низк./Средн./Высок.

- **Принцип «бесплатное не ухудшается»:** где функция влияет на доверие/безопасность всех пользователей, рекомендую **оставить бесплатной** — помечено ⚑.

## 2. Карточки (12 критериев)

### B-01. Коммерческая лицензия организации (офлайн, подписанный файл)
1. **Аудитория:** МСБ и средние компании, которым нужна легальная покупка «для работы» и счёт.
2. **Проблема:** юрлицу нужен документ о праве использования и учёт мест; онлайн-активация неприемлема для офлайн-политики продукта.
3. **Спрос:** модель «бесплатно лично — платно бизнесу» работает у PhraseExpress [R]; Kavanati продаёт лицензии на компьютер организациям [R]; Typinator Business [R]. Прямых запросов к KeySwitch нет [A].
4. **Конкуренты:** PhraseExpress — разовая per-user, пул лицензий на SQL Server [R]; TextExpander/Text Blaze — облачные организации per-user [R]; JetBrains — офлайн-коды активации [R].
5. **Готовность платить:** доказана для экспандеров (Text Blaze $6.99/польз./мес, TextExpander $99.96/польз./год, PhraseExpress ≈ $50–250 разово — [R], не подтверждено); для переключателя — не проверена; потребительский ориентир Caramba $4.99/год [R] задаёт низкий потолок [A].
6. **Ценность:** для пользователя — нулевая функционально; для покупателя — юридическая чистота.
7. **Сложность (предв.):** M — формат лицензии (JSON + Ed25519-подпись, поля: организация, кол-во мест/site, срок обновлений), проверка в `ks-storage`/оболочке, чтение из `HKLM\Software\Policies\KeySwitch` или `%ProgramData%`; без сети.
8. **Поддержка:** Средн. — выдача, продление, потерянные ключи, счета.
9. **Производительность:** пренебрежимо (проверка подписи при старте).
10. **Безопасность (для CISO):** ключ подписи вендора — критичный секрет (HSM/офлайн); парсер лицензии — новый вход (fuzz, `deny_unknown_fields`); **не** проверять лицензию анализом текста (антипример PhraseExpress — эвристика «коммерческого использования» по содержимому [R]; запрещено CLAUDE.md п.1).
11. **GDPR/право (для CLO):** в файле — название организации, не ПДн сотрудников; EULA для B2B; зависимость от лицензии кода (MI-19, D-09 публичный репозиторий); налоги/НДС (N-7).
12. **Коммерческая ценность:** Высок., если владелец выберет модель «коммерческое использование платно»; иначе Средн. (продажа только управления/поддержки).
**Сервер:** не нужен. Онлайн-пул/плавающие лицензии — КОНЦЕПЦИЯ → владелец.

### B-02. MSI per-machine, тихая установка, winget-манифест, гайд развёртывания ⚑
1. **Аудитория:** любые ИТ-администраторы, включая МСБ с «приходящим» админом.
2. **Проблема:** NSIS/per-user установка плохо управляется Intune/ConfigMgr; нужны `/qn`, ProductCode, `ALLUSERS=1`.
3. **Спрос:** Средн.–Высок.: админы предпочитают MSI [R splashtop, acrobits, ISV playbook]; Wingetly публикует тихие ключи Caramba [R].
4. **Конкуренты:** PowerToys (MSI/winget, бесплатно) [R]; Caramba — winget/Intune-параметры [R].
5. **Готовность платить:** низкая — рынок считает это гигиеной [A].
6. **Ценность:** Высок. для ИТ; для пользователя — косвенно.
7. **Сложность:** M — Tauri 2 MSI (WiX v3, только на Windows-раннере), per-machine scope через WiX-фрагменты, WebView2 offline/fixed runtime (+127/180 МБ) [R tauri docs]; автозапуск для всех пользователей; детект-правила.
8. **Поддержка:** Средн. (варианты окружений, VDI).
9. **Производительность:** размер установщика растёт при офлайн-WebView2.
10. **Безопасность:** per-machine установка в `Program Files` (защита от подмены пользователем — плюс); custom actions минимизировать; подпись MSI обязательна (Smart App Control [R]).
11. **Право:** нет ПДн; лицензии WiX/WebView2-распространения — CLO/AGENT 16.
12. **Коммерция:** Низк. напрямую; Высок. как условие любых B2B-продаж. **Рекомендация: бесплатно** — платная установка ухудшала бы бесплатную версию для организаций и противоречит V4 п.5 [A].

### B-03. Базовые политики HKLM / ADMX
1. **Аудитория:** средние компании с GPO/Intune.
2. **Проблема:** ИБ хочет зафиксировать поведение: хоткей, исключения, выключить Macro Studio/доступ к буферу/W2.
3. **Спрос:** образец PowerToys ADMX + Intune OMA-URI [R]; MI-16 [V]; прямых запросов — нет.
4. **Конкуренты:** PowerToys (бесплатно); у переключателей не найдено [R].
5. **Готовность платить:** Средн. в составе пакета, низкая отдельно [A].
6. **Ценность:** Высок. для ИТ/ИБ; для пользователя — предсказуемость.
7. **Сложность:** M — чтение `HKLM\Software\Policies\KeySwitch` (приоритет над пользовательскими), блокировка UI-элементов с пометкой «управляется организацией», ADMX/ADML (en, ru), тесты.
8. **Поддержка:** Средн. (документация политик).
9. **Производительность:** чтение реестра при старте/по `RegNotifyChangeKeyValue` — пренебрежимо.
10. **Безопасность:** политики только из HKLM (запись — админ); политика может только **сужать** права, не расширять (например, нельзя включить Enter/Tab в макросах политикой без локального согласия — вопрос CISO); политика `MacroStudio=Disabled` должна не запускать `ks-sandbox.exe` вообще (для allow-list ИБ, ср. T1059.010 [R]).
11. **Право:** нет ПДн.
12. **Коммерция:** Средн. **Вариант:** «выкл. Macro Studio» — бесплатно ⚑ (безопасность), остальное — Business.

### B-04. Командные макросы/шаблоны (подписанный пакет организации, несколько слотов)
1. **Аудитория:** поддержка, колл-центры, продажи, юр. отделы — единые формулировки.
2. **Проблема:** повторяющиеся ответы, единый стиль; сотрудники не должны писать скрипты сами.
3. **Спрос:** доказан для экспандеров — общие библиотеки ядро Business-тарифов TextExpander/Text Blaze [R]; эффект на AHT — цифры слабые [R].
4. **Конкуренты:** TextExpander (облако), PhraseExpress (SQL/NAS), Typinator (NAS/WebDAV), Espanso (git-пакеты, без управления) [R]. **Отличие KeySwitch:** исполнение в песочнице (Wasmtime + LPAC) — у экспандеров скрипты с полными правами [V AGENT 10].
5. **Готовность платить:** Высок. у экспандеров; для KeySwitch — сравнение будет с ними по мощности, где KeySwitch слабее (1 слот, хоткей, без аббревиатур — NG-1) [A].
6. **Ценность:** Средн.–Высок. для этих ролей.
7. **Сложность:** L — несколько слотов (сейчас 1, NG-5), формат пакета (исходник + манифест разрешений + подпись org-ключом), доверие к ключу организации из HKLM, UI «только чтение», сопоставление хэшей (разрешение на буфер привязано к хэшу исходника [V SYSTEM_ARCHITECTURE §5]).
8. **Поддержка:** Высок. (пишут макросы заказчики, ошибки скриптов).
9. **Производительность:** холодный старт песочницы на каждый запуск при доступе к буферу [V §5]; для шаблонов без буфера — «тёплый» процесс.
10. **Безопасность:** **требует пересмотра D-07 («импорт чужих макросов в v1 отсутствует») → владелец**; подписанный пакет = доставка кода — threat model (T-xx) расширить; Enter/Tab в макросах организации — по-прежнему отдельное разрешение (D-18).
11. **Право:** содержимое шаблонов — данные заказчика на его устройствах; вендор их не получает.
12. **Коммерция:** Высок. — самый «продаваемый» кандидат, но и самый рискованный.
**Сервер:** не нужен (Intune/GPO/файловый ресурс). Облачная синхронизация — КОНЦЕПЦИЯ.

4. **Конкуренты:** Kright/RuSwitcher — правила по приложению (личные) [V AGENT 10]; корпоративных — не найдено.
5. **Готовность платить:** в составе пакета.
6. **Ценность:** Средн.
7. **Сложность:** S–M — профиль уже есть в архитектуре (`ks-engine`), нужен источник «из политики».
8. **Поддержка:** Средн. (некорректные профили ведут к неудачной вставке).
9. **Производительность:** нет влияния.
10. **Безопасность:** профиль может разрешить W2/вставку через буфер — это ослабление; профили организации только подписанные; не позволять профилю снимать безусловные исключения D-05 (пароли, повышенные окна).
11. **Право:** нет.
12. **Коммерция:** Средн.

3. Спрос: Низк.–Средн. [A].

5. Готовность платить: низкая.
6. Ценность: Средн.

9. Производительность: —.

12. Коммерция: Средн. косвенно. **Рекомендация: бесплатно и публично.**

4. Конкуренты: TextExpander (облако) [R]; локальных — не найдено.
5. Готовность платить: низкая отдельно.
6. Ценность: Низк.–Средн.
7. Сложность: M — агрегаты по дням: версия, политика применена, число операций/отказов по кодам причин; файл в `%ProgramData%`, сбор — инструментами заказчика (Intune Remediations/ConfigMgr inventory).

9. Производительность: пренебрежимо.

12. Коммерция: Низк.–Средн. **Рекомендация:** позже, после интервью.
**Сервер:** не нужен; дашборд вендора — КОНЦЕПЦИЯ и конфликт с NG-7.

## 3. Выводы для Product Analyst
