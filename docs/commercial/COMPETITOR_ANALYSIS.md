## 1. Ключевые выводы

1. **Ценовой пол базовой функции = 0.** Punto (бесплатно), Kright/RuSwitcher/SimpleSwitcher/LangSwitcher (MIT/OSS, бесплатно) [V/R]. Платят только за «надстройку» или удобство на Mac.
2. **Наблюдаемые платные цены в нише переключателей — низкие:** Caramba Pro $4,99/год (Win, 3 ПК), $6,99/год (Mac), 499 ₽/год (Allsoft) [R]; Lang Switcher (Mac) $7,99–11,99/год или **$29,99 пожизненно** [R]; Boomkey ≈ $14,99 [R]. Это ориентир «потолка B2C» для чистого переключателя [A].
3. **Смежные инструменты (экспандеры, утилиты) берут больше:** PhraseExpress 99,95 / 149,95 / 249,95 € разово (май 2026) [R]; TextExpander ~$3,33/мес при годовой оплате [R]; aText $4,99/год или $29,99 навсегда [R]; DisplayFusion Pro $34 разово, пожизненно [R]; ClipboardFusion Pro от $9,50 [R]. Пользователи платят за **автоматизацию текста**, а не за переключение раскладки [A].
4. **Корпоративные функции у переключателей почти отсутствуют**: единственный сигнал — параметры тихой установки Caramba Pro в winget-каталоге [R]. У экспандеров (PhraseExpress Enterprise, TextExpander Business, Grammarly Enterprise — SSO/DLP/аудит) — есть [R]. → AGENT 17.
5. **Главные жалобы на рынке** (см. `2026-11-10-user-needs.md`): кейлоггер/телеметрия, ложные автосрабатывания, «не работает в приложении X», потеря буфера, заброшенность, подписка за базовую функцию.
6. **Пустые места рынка [A]:** (а) без глобального хука и сети вообще; (б) песочница для пользовательского кода; (в) честная матрица совместимости; (г) офлайн-лицензирование без активации — ни у кого из переключателей не найдено.

## 3. Заметки по конкурентам (дополнения к competitive-landscape)

### Punto Switcher — коммерческая модель «бесплатно за счёт экосистемы»
- Монетизация косвенная: установщик предлагает Яндекс Браузер с Алисой и расширение поиска [R]. Для KeySwitch неприменимо (D-14/сеть/бандлинг) [A].
- Число пользователей не опубликовано — **пробел**. Существует с 2001 г., куплен Яндексом в 2008 г. [R: https://3dnews.ru/565834].
- **Угроза/возможность [A]:** Punto — «база пользователей, которую можно переманить», но эти пользователи привыкли к «бесплатно и автоматически». Платить за переключатель они вряд ли будут; их можно привлечь в Free, а Premium продавать тем, кто приходит к Macro Studio.

### Caramba Switcher — единственный найденный прямой ориентир подписки
- Модель: Free Classic + Pro. Windows Pro $4,99/год на 3 ПК — очень низкий порог; Mac $6,99/год [R]. Pro для Windows «появился недавно» [R]. Свежие цены 2026 **не подтверждены** (сайт недоступен, поиск не находит).
- Корпоративное: только тихая установка в winget-каталоге [R].
- **Урок [A]:** подписка за базовую функцию возможна, но вызывает негатив и держит цену у $5/год. Если KeySwitch Free даёт полную конвертацию, сравнение с Caramba Pro будет «бесплатно vs $5/год» — в нашу пользу.

### Kright — главный OSS-конкурент по философии
- Распространение: GitHub Releases + **Microsoft Store** («тот же подписанный установщик»), winget не упомянут [V: https://raw.githubusercontent.com/walteryaron/kright/HEAD/README.md]. Цены/донатов нет [V].
- Функции, которые у нас могли бы стать «Premium», у Kright **бесплатны**: правила по приложению, правила по контакту (Teams), авто-латиница в полях email/URL/пароль, распознавание 11 языков (EN, HE, RU, UK, BG, SR, MK, EL, FA, HY, KA) [V]. → Эти функции **нельзя** продавать как Premium без риска «нас сравнят с бесплатным Kright» [A].

### RuSwitcher / SimpleSwitcher / LangSwitcher
- Бесплатно + донаты [V]. Задают ожидание: «списки never/always», 16 языков интерфейса, любые триггеры — бесплатно [V]. → Языковые и настроечные функции — в Free [A].

### Lang Switcher (Mac) — пример «год или навсегда»
- Одновременно годовые планы и пожизненная $29,99 [R]. Сигнал: в нише утилит продавцы предлагают lifetime как альтернативу подписке [A].

### PhraseExpress / TextExpander / aText — платят за автоматизацию текста
- PhraseExpress: бесплатно для личного использования, платно для профессионального — модель «личное бесплатно, работа платно» [R]. Цены 100–250 € разово (май 2026) [R].
- TextExpander: подписка, без постоянного бесплатного плана [R].
- aText: и годовая, и пожизненная [R].
- **Урок [A]:** готовность платить в соседней категории — за **сниппеты, шаблоны, библиотеки, командную работу**. Macro Studio — ближайший для KeySwitch мост в эту категорию. Но экспандеры работают через перехват набора (триггер-аббревиатуры) — у KeySwitch его не будет (D-14): только хоткей/палитра.

### Raycast / PowerToys — эталоны UX и ценовой лестницы
- Raycast: бесплатный лаунчер + Pro ~$8–10/мес (ИИ, синхронизация, темы) [R]. PowerToys — бесплатен [R]. Ожидание пользователей Windows-утилит: «база бесплатна, платно — облако/ИИ» [A]. Для KeySwitch облако/ИИ — противоречат принципам; значит, наш Premium должен строиться на **локальной** ценности.
