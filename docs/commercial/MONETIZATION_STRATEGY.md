## 1. Главное

1. **База рынка — бесплатно** (Punto, OSS-конкуренты) [V/R]. Монетизируется только надстройка: Macro Studio сверх Free, сниппеты, профили, поддержка; корпоративная линия — AGENT 17.
2. **Наблюдаемый B2C-коридор в нише переключателей — от ~$5/год до ~$30 разово** (Caramba Pro $4,99/год; Lang Switcher $7,99–11,99/год или $29,99 навсегда; Boomkey ≈ $14,99) [R]. В соседней категории автоматизации текста — до 100–250 € разово (PhraseExpress) [R].
3. **Подписка за базовую функцию вызывает негатив** (Caramba Mac [R]); для утилит распространены **разовая покупка** и **«навсегда» рядом с годовой** (Lang Switcher, aText) [R].
4. **Без сети и телеметрии подходят только офлайн-лицензии**: подписанный файл/ключ, проверяемый локально открытым ключом; отзыв и учёт мест невозможны без сервера — это надо принять как свойство модели [R: Keygen/LicenseSpring/Cryptolens docs через поиск].
5. **Блокеры до любой продажи:** название/товарный знак (MI-20), лицензия кода (MI-19: open core и CRA), CRA-обязанности производителя (с 2026-09-11 отчётность) [R], платежи из РФ/РБ недоступны у крупных MoR (Paddle) [R].

## 5. Лицензирование и активация, совместимые с офлайн/без телеметрии — **для CISO + CLO + ARCH**

Факты о технике (все [R], документация вендоров через поиск): подписанные криптографически лицензионные файлы, распространяемые офлайн (e-mail, USB), проверяются встроенным открытым ключом [https://keygen.sh/docs/api/cryptography]; Ed25519 — распространённая схема; извлечение открытого ключа не позволяет подделать лицензию [https://infosecwriteups.com/asymmetric-signing-machine-fingerprinting-and-offline-grace-periods-building-a-license-system-d8dd5678e1cb]; офлайн-приложение **не может узнать об отзыве** после подписания, учёт мест между устройствами требует сервера [https://dev.to/nicodemanez/i-compared-the-licensing-tools-for-my-indie-mac-app-the-honest-breakdown-40a5]; есть OSS-библиотеки с офлайн-CLI (Signet) [https://github.com/franzos/signet]; «air-gapped» активация через QR/код [https://github.imc.re/keygen-sh/air-gapped-activation-example ; https://licensespring.com/solutions/offline-licensing].

| Вариант | Как работает | Приватность | Защита от копирования | Риски / вопросы |
|---|---|---|---|---|
| **L-1. Подписанный лицензионный файл без привязки к машине** (рекомендуемый для оценки) | Продавец подписывает {ID лицензии, издание, срок обновлений, число устройств-«честное слово»}; приложение проверяет подпись локально | Лучшая: нет отпечатка ПК, нет сети; e-mail в файл **не класть** (только ID) | Слабая (файл можно передать) | Принять «честную» модель; в open source проверку можно вырезать — это свойство OSS, не уязвимость [A]. CISO: хранение ключа, парсер файла как входные данные. CLO: условия лицензии |
| L-2. Файл с привязкой к машине (отпечаток) | Пользователь передаёт отпечаток (код/QR) вручную → получает файл | Хуже: отпечаток — потенциально идентифицирующие данные устройства | Средняя | GDPR (CLO); смена железа → поддержка; противоречит духу «не собираем» |
| L-3. Ключ-строка с подписью (короткий формат) | То же, что L-1, в виде ключа для копирования | Как L-1 | Слабая | Длина ключа (Ed25519 подпись 64 байта → длинная строка) [A] |
| L-4. Лицензия Microsoft Store (покупка/дополнения в Store) | Права проверяет Store | Store — сервис ОС; **вопрос CISO:** создаёт ли Store API сетевой вызов из нашего процесса (нарушение CLAUDE.md п.2?) | Средняя | Комиссия 15 % или своя коммерция 0 % [R]; привязка к учётной записи Microsoft |
| L-5. Без технической лицензии (honor system: «Premium-функции открыты, покупка — поддержка/разрешение на коммерческое использование») | Как PhraseExpress «личное бесплатно, работа платно» [R] | Идеальная | Нет | Выручка зависит от честности; проще всего для OSS |
| ~~Онлайн-активация / периодическая проверка~~ | Сервер лицензий | Сеть + телеметрия | — | **Недопустимо** (CLAUDE.md п.2) |

**Принцип истечения [A, для CLO/PA]:** при истечении срока (подписка/обновления) функции, уже купленные для установленной версии, **не отключаются задним числом**; прекращается право на *новые* версии. Иначе офлайн-приложение превращает дату ПК в «выключатель» и наказывает пользователей с неверными часами.
