## 0. Главное (для Project Director)

1. **Ядро монетизации — расширенная Macro Studio (слоты, палитра сниппетов) для B2C и управляемость + юридическая чистота для B2B.** Конвертация, языки, защиты, ограничительные политики безопасности, документация для ИБ — FREE. Это совпадает у AGENT 10 и AGENT 17.

3. **Оба пакета исследований написаны по V4 и частично устарели относительно V7/D-22/D-24/D-25** (сеть, автообновления, лицензия кода, macOS). Это главный источник противоречий (§3). Рекомендация: AGENT 10 и AGENT 17 точечно обновить формулировки после C-3, не переписывая выводы.
4. **Три вопроса блокируют раскладку по уровням и требуют решения владельца:** (а) модель «бесплатно лично / платно для коммерческого использования» — да или нет (§3, X-05); (б) пересмотр D-07/NG-5 (импорт/пакеты макросов, несколько слотов) — без него P-01, B-04, E-05, MI-27 не реализуемы; (в) состав MVP-добавлений из MI-01…27 (§2).

## 6. Непроверяемые формулировки (для исправления до C-8)

1. «Бесплатная версия искусственно не ограничивается» — непроверяемо без зафиксированной базовой линии FREE → V-6 (список, с которым сравнивается каждая версия).
2. «Уровни видны в интерфейсе без навязчивости» (CPP C-5) — нужно измеримое: «ни одного экрана/уведомления о покупке во время конвертации и выполнения макроса; упоминание платного уровня — только в разделе X».
3. MI-01 «живые проверки» — проверяемо только для утверждений, подписанных CISO (CISO-8); формулировки о «компьютере» вместо «процесса KeySwitch» — непроверяемы.
4. «Политики только сужают права» (E-06, B-03) — требует перечня политик и теста «политика не снимает D-05/D-14/D-27» для каждой.
5. «Спрос подтверждён» в любом будущем решении — только с порогами V-1/V-2, а не с наличием цен у конкурентов.
