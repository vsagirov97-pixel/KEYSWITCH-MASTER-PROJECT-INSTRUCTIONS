**Предварительность оценок.** Критерии «техническая сложность» и «производительность» — **предварительно, проверяет System Architect (AGENT 03)**; «безопасность» — **предварительно, проверяет CISO (AGENT 11)**; «GDPR/право» — **предварительно, проверяет CLO (AGENT 12)**. ## 0. Принципы отбора (ограничения, которые не обсуждаются)

1. **Free не ухудшается искусственно** (V4 п.5). Всё, что сегодня в плане v1 (`docs/01-prd.md`), остаётся бесплатным: конвертация, безопасность, отказ при риске, Ctrl+Z, 1 слот Macro Studio (текст/JS/Python), Diagnostics.
2. **Безопасность и приватность не продаются**: защиты (пароли, буфер D-13, песочница D-08, отсутствие сети) не могут быть Premium.
3. **Никакой сети в runtime** (CLAUDE.md п.2) → облачная синхронизация, онлайн-активация, проверка подписки по сети исключены.
4. **Никаких хуков клавиатуры** (D-14) → триггеры-аббревиатуры экспандеров, Shift×2, автопереключение «as you type» невозможны и не могут быть Premium.
5. **Не продавать то, что бесплатно у ближайших OSS-конкурентов** (Kright, RuSwitcher) [V] — иначе Premium проигрывает сравнение.

## 1. Шкала

Для каждого критерия: **3** — высокий/благоприятный, **2** — средний, **1** — низкий/неблагоприятный (для сложности, стоимости поддержки, нагрузки и рисков: 3 = *низкие* затраты/риски). «Сила доказательств спроса»: С (сильное) / Ср (среднее) / Сл (слабое) / Нет. Итоговая рекомендация — экспертное мнение [A], не сумма баллов.

## 3. Карточки (12 критериев V4)

### P-01. Дополнительные слоты Macro Studio
1. **Аудитория:** разработчики, «тяжёлые» пользователи текста (B2C_USER_NEEDS 2.6, 2.9).
2. **Проблема:** один слот (FR-MACRO-1) покрывает одну задачу; реальная работа — 3–10 повторяющихся операций [A].
3. **Спрос:** **Ср** — рынок экспандеров/автоматизации платный (PhraseExpress 99,95–249,95 € [R], TextExpander ~$40/год [R], aText $29,99 навсегда [R]); прямого спроса на «слоты» нет — аналог в нише переключателей не найден [A].
4. **Конкуренты:** у переключателей нет макросов в песочнице [A]; у AHK/Espanso — неограниченно и бесплатно, но с полными правами [V].
5. **WTP:** 2 — по аналогии с экспандерами; проверка интервью обязательна.
6. **Ценность:** 3 — превращает Macro Studio из демонстрации в рабочий инструмент.
7. **Сложность (предв., ARCH):** 2 — архитектура допускает несколько слотов (`docs/01-prd.md`: «архитектура допускает, UI — нет»); нужны UI списка, конфликт хоткеев на N слотов, хранение.
8. **Поддержка:** 2 — больше макросов = больше вопросов «почему мой скрипт не работает».
9. **Производительность (предв.):** 3 — исполнение по нажатию, одна песочница за раз [A].
10. **Безопасность (предв., CISO):** 2 — каждый слот со своими разрешениями (D-07, D-18); рост поверхности — линейный, модель не меняется.
11. **GDPR/право (предв., CLO):** 3 — данные локальные; вопрос лицензии кода (MI-19) — можно ли «запирать» слоты в открытом коде.
12. **Коммерческая ценность:** **3** — уже заложено в ТЗ (§11 «бесплатно — один слот»), понятная граница Free/Premium без ухудшения Free.
**Вывод:** главный кандидат. Варианты границы (владельцу): Free = 1 слот (как ТЗ) или Free = 2–3 слота, Premium = больше. Аналитик рекомендует **не уменьшать** Free ниже ТЗ.

### P-02. Расширенная автоматизация макросов
1. **Аудитория:** разработчики, power-users.
2. **Проблема:** нужны макросы «по приложению», цепочки (трансформация → вставка), переменные (дата/время), диалог ввода параметра.
3. **Спрос:** **Ср** — PhraseExpress/Raycast/AHK продают/дают такие возможности [R/V].
4. **Конкуренты:** AHK, Espanso (формы, regex, скрипты [V]), Raycast Script Commands [R].
5. **WTP:** 2.
6. **Ценность:** 2.
7. **Сложность (предв.):** 1 — расширение API песочницы, новые разрешения, UI.
8. **Поддержка:** 1 — сложные сценарии = дорогая поддержка.
9. **Производительность:** 2.
10. **Безопасность (предв., CISO):** 1 — каждое расширение API — новая поверхность; диалоги ввода из песочницы — риск фишинга UI; макросы по приложению требуют знать передний процесс.
11. **GDPR (предв.):** 3.
12. **Коммерческая ценность:** 2.
**Вывод:** только после P-01 и после модели угроз на каждое расширение API. Не включать клавиши вне белого списка D-07.

### P-03. Палитра сниппетов/шаблонов по хоткею (новая идея MI-24*)
1. **Аудитория:** тяжёлые пользователи текста, поддержка, преподаватели.
2. **Проблема:** экспандеры работают через аббревиатуры (перехват набора) — нам запрещено (D-14). Альтернатива без хуков: хоткей открывает компактное окно поиска по библиотеке текстов/шаблонов → выбор → безопасная вставка тем же путём, что и конвертация.
3. **Спрос:** **Ср** — категория экспандеров платная [R]; палитра — стандартный паттерн Raycast (сниппеты) [R].
4. **Конкуренты:** PhraseExpress, TextExpander, aText, Raycast; у переключателей — только EveryLang (сниппеты) [R].
5. **WTP:** 2.
6. **Ценность:** 3 — снимает лимит слотов для *текстовых* макросов без кода.
7. **Сложность (предв.):** 2 — окно поверх, поиск, хранение; вставка — переиспользует существующий конвейер.
8. **Поддержка:** 2.
9. **Производительность:** 3 (при умеренном объёме библиотеки).
10. **Безопасность (предв., CISO):** 2 — тексты сниппетов — пользовательские данные на диске (шифрование DPAPI?); окно палитры получает фокус → нужно вернуть фокус в исходное поле без хуков.
11. **GDPR (предв.):** 2 — сниппеты могут содержать персональные данные третьих лиц (шаблоны писем) — только локально.
12. **Коммерческая ценность:** **3** — мост к платной категории без нарушения принципов.
**Вывод:** второй кандидат. Можно: Free — N сниппетов, Premium — без ограничений (граница — решение владельца).

### P-05. Профили пользователя

5. **WTP:** 2 (power-user).
6. **Ценность:** 2.
7. **Сложность (предв.):** 2 — переключение = перерегистрация `RegisterHotKey` + смена политики.
8. **Поддержка:** 2.
9. **Производительность:** 3.
10. **Безопасность (предв.):** 3 — автопереключение профиля по переднему окну пересекается с MI-09 (WinEvent) → CISO.
11. **GDPR:** 3.
12. **Коммерческая ценность:** 2.
**Вывод:** Premium-кандидат второй волны; ручное переключение профиля — проще и безопаснее автоматического.
