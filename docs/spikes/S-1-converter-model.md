# S-1 — Конвертер раскладок с языковой моделью

**Вердикт: подтверждено** (на уровне ядра, Linux). Подход «физическое соответствие клавиш + выбор варианта по модели языка» решает проблему пунктуации из ТЗ.

## Что сделано
- `crates/ks-core/layouts/{en-us,ru}.layout` — раскладки как данные: скан-код → обычный/Shift символ (D-15). Источник — раскладки Windows US (00000409) и Russian (00000419).
- `crates/ks-core/src/layout.rs` — парсер и проверка (дубликаты клавиш/символов — ошибка).
- `crates/ks-core/src/model.rs` — модель: стоимость известного слова по частоте + символьная триграммная модель для незнакомых слов.
- `crates/ks-core/src/convert.rs` — конвертация:
  - каждый символ переносится через физическую клавишу;
  - небуквенный символ, который на другой раскладке даёт другое (`,`→`б`, `?`→`,`), получает 2 варианта;
  - все комбинации (≤ 2¹⁰ на слово) оцениваются: стоимость слов + априорные штрафы пунктуации (внутри слова — дорого; `.?!` в конце текста — дёшево);
  - `detect` — какие языки присутствуют (одиночный / смешанный текст);
  - `convert` — с оценкой уверенности (`Low`, если исходный текст выглядит правдоподобнее результата);
  - `convert_mixed` — смешанный текст: фрагменты целевого языка и настоящие иностранные слова сохраняются; спорные случаи → `Low`.
- `Conversion` не печатает текст в `Debug` (T-09).

## Доказательства (Linux, этот хост)
`cargo test -p ks-core`: **30 тестов, 0 провалов** (4 модульных + 26 интеграционных). Ключевые:

| Вход | Направление | Результат |
|------|-------------|-----------|
| `Ghbdtn, rfr ltkf?` | EN→RU | `Привет, как дела?` |
| `Ghbdtn? rfr ltkf&` (реально набранное) | EN→RU | `Привет, как дела?` |
| `k.,k.` | EN→RU | `люблю` |
| `j,sxyj` | EN→RU | `обычно` |
| `ytn.` | EN→RU | `нет.` |
| `xbckj 3.14` | EN→RU | `число 3.14` |
| `Руддщ` / `Руддщб цщкдв!` | RU→EN | `Hello` / `Hello, world!` |
| `ш вщтэе лтщц` | RU→EN | `i don't know` |
| `Привет, rfr ltkf?` | смешанный → RU | `Привет, как дела?` |
| `Открой google, gj;fkeqcnf` | смешанный → RU | `Открой google, пожалуйста` |
| `Hello, how are you?` | EN→RU | уверенность `Low` (не менять) |

Плюс инвариант на 300 псевдослучайных строках × 3 режима: длина, пробелы, переводы строк и цифры сохраняются, паник нет.

Windows CI: тесты ядра выполняются и в job «Windows build» (`cargo test --workspace`).

## Не проверено
- Качество на большом реальном корпусе ошибочно набранных текстов — только 26 сценариев. Нужен корпус QA (≥ 500 фраз) до GATE 4.
- Поведение на Windows в реальных приложениях — вне рамок S-1.
- Пороги (`MIXED_MARGIN = 2.0`, штрафы пунктуации) подобраны вручную на этих тестах — возможна переобученность.

4. Для украинского (общие буквы с русским) `detect` потребует доработки: сейчас язык определяется по алфавиту.
