# ADR-0010 — Закрытая лицензия KeySwitch

Статус: **Accepted** · Дата: 2026-11-10 · Решения: D-22(3), D-09 (публичный репозиторий) · Автор: AGENT 03 (технические последствия), владелец — решение

## Контекст
Репозиторий публичный ради бесплатных Windows-раннеров (D-09), но продукт коммерческий (V4).

## Проблема
Публичный код без лицензии или с открытой лицензией определяет, что можно делать с кодом и какие сторонние компоненты допустимы.

## Альтернативы
1. Открытая лицензия (MIT/Apache) — противоречит коммерческой модели владельца.
2. Copyleft (GPL) — несовместимо с закрытыми частями.
3. **«Все права защищены» (`LICENSE`), сторонние компоненты — по своим лицензиям.**

## Решение
Код KeySwitch — проприетарный; зависимости — только с лицензиями из allow-list `deny.toml` (MIT, Apache-2.0, BSD-3-Clause, Zlib, MPL-2.0, …); copyleft (LGPL/GPL) — не в продукте (PySide6 — только CI-фикстура при подтверждении CLO, D-19(e)).

## Обоснование
Сохраняет коммерческие варианты владельца; allow-list даёт автоматическую проверку.

## Последствия
- `THIRD_PARTY.md`/SBOM с текстами лицензий (CPython PSF-2.0, шрифты OFL) обязательны в установщике.
- Внешние контрибьюции требуют соглашения (CLO).
- Условия GitHub для публичного репозитория с закрытой лицензией — оценка CLO.

## Проверка
`cargo deny check licenses` в CI; `LICENSE_REGISTER.md` (CLO).
