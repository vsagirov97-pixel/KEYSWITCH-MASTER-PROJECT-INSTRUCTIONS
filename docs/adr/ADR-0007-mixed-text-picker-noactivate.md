# ADR-0007 — Окно выбора языка смешанного текста: `WS_EX_NOACTIVATE`

Статус: **Accepted** · Дата: 2026-11-10 · Решения: X-4 (CISO, `SECURITY_REVIEW.md` §4.5), D-14 · Автор: AGENT 03

## Контекст
Для смешанного текста (часть EN, часть RU) пользователь выбирает целевой язык.

## Проблема
Активация собственного окна уводит фокус из поля: в веб-композерах blur может отправить черновик, возврат фокуса ненадёжен (`SetForegroundWindow`), пользователь может печатать «в никуда».

## Альтернативы
1. Активируемое нативное окно (AV2 P-07, FR §5.3) — гонки фокуса (R-A5).
2. Окно WebView2 — ещё медленнее фокус и зависимость от IPC.
3. **Неактивируемое нативное окно + временные `RegisterHotKey` для `1`/`2`/`Esc`.**

## Решение
Win32-окно `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_TOPMOST`, без пользовательского текста; хоткеи регистрирует T1 только на время показа (RAII-guard, таймаут 10 с); ошибка регистрации → отмена операции (никаких хуков). После выбора — перечитать, сравнить хэш, проверить отпечаток фокуса. Состояние `Refocus` и исход `CouldNotActivate` упразднены. macOS — неактивируемая `NSPanel`.

## Обоснование
Фокус поля не меняется → нет побочных эффектов blur; соответствует D-14.

## Последствия
На ≤ 10 с клавиши `1/2/Esc` перехвачены в других окнах. Запасной вариант с активацией — только после данных S-2 и повторного одобрения CISO.

## Проверка
S-2 п.5: фокус поля не меняется; хоткеи сняты по таймауту и после аварийного выхода.
